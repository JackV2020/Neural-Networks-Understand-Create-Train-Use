
# spirals

This is a neural network that reports 8 different properties of spirals.

 - archemedian or triangular wise
 - clockwise or counter clockwise
 - background color
 - spiral color
 - big or small
 - thick or thin line
 - one or two turns
 - rotation in steps of 45 degrees

To run the scripts to generate, train and test spirals, you need to create a virtual environment.

 - python3 -m venv my_venv
 - source my_venv
 - when you do not have a GPU:
    - pip install numpy pillow tqdm scikit-learn ai_edge_litert tensorflow-cpu
 - when you do have a GPU:
    - pip install numpy pillow tqdm scikit-learn ai_edge_litert tensorflow
 - deactivate

## Generate images

Modify the variable 'data_root' in generate_spirals_8_labels.py so it generates the images in the location you want it to.

Then run the script with 'my_venv/bin/python3 generate_spirals_8_labels.py'.

The spirals images generated by the script have 8 labels:

 - archemedian or triangular wise
 - clockwise or counter clockwise
 - background color
 - spiral color
 - big or small
 - thick or thin line
 - one or two turns
 - rotation in steps of 45 degrees

## Training

Modify the variable 'data_root' in train_8_labels.py so it uses the images you created before.

The model in the training script has more properties so you may want to have a look at it.

Then run the script with 'my_venv/bin/python3 train_8_labels.py'.

The training script generates the keras and tflite models and saves the pkl file.

## Testing

The test script can be used to analyse images from the test folder.

Run the script with 'my_venv/bin/python3 test_picture_lite_8_labels.py path-to-test-file.jpg'

## Web app

You can use a web app on your web server.

The main README.md of this repository explains how to setup apache with php on a Raspberry Pi.

I assume you did that so you can create a complete setup for this application.

You need to install some python modules in a virtual environment and after that the application.

Start a terminal and...

 - sudo -i
 - mkdir /var/www/html/spirals
 - chown www-data: /var/www/html/spirals
 - cd /var/www/html/spirals

The next command will take 'some' time on a Raspberry Pi 3B.....

 - python3 -m venv my_venv
 - source my_venv/bin/activate
 - pip install numpy pillow ai_edge_litert scikit-learn
<br>Or when you need specific versions like I did :
 - pip install numpy pillow ai_edge_litert==1.3.0 scikit-learn==1.7.0
    - on the Raspberry Pi we use ai_edge_litert, not tensorflow
    - we need scikit-learn to read the pkl file, not to learn something
 - deactivate

 - copy the next files to /var/www/html/spirals:
   - index.php
   - test_picture_lite_8_labels.py
   - label_encoders_8_labels.pkl
   - model_8_labels.tflite
 - and when you want to allow test files to be downloaded
   - test.php
   - folder test with your test images

Now you should be able to browse to  ```http://ip_address_of_your_Raspberry_Pi/spirals``` and use the application to analyse pictures.
